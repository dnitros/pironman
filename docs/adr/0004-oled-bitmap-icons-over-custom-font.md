# Layer hand-drawn bitmap icons on the OLED display, without adding a font-rendering library

PER-19 already draws OLED text with `basicfont` from `golang.org/x/image`, a zero-asset embedded bitmap font, and that choice stands. PER-20 asked whether pixel-parity icons and a custom font from the original Python daemon (`sunfounder/pm_auto`) were worth adding on top. We considered three options: embedding `UbuntuSans-Regular.ttf` (pm_auto's font, UFL-1.0-licensed and technically embeddable) with `x/image/font/opentype`/`sfnt` rasterization to match pm_auto's typography exactly; generating a custom pre-rendered bitmap font shaped like `basicfont` but matching UbuntuSans's letterforms; and hand-drawn 1-bit bitmap icons blitted directly, with text staying on `basicfont`. The TTF option buys the most fidelity but costs the most — a ~400KB-class font asset, a new rasterization dependency, and a per-frame glyph-cache problem to solve, all to re-solve a "readable labels" problem `basicfont` already solves; `l-you/pironman5-go`, an independent Go port, evaluated the same ground and also stayed `basicfont`-only. The custom bitmap font duplicates what `basicfont` already provides for a purely cosmetic letterform match, with an offline generation step and no functional payoff. We chose hand-drawn bitmap icons for a small set (network type, disk type, error/disconnected state, not all 18 of pm_auto's icons) at pm_auto's reference pixel sizes, embedded via `go:embed` and blitted with the same pixel-loop pattern `l-you/pironman5-go` already uses for its heart icon — no new dependency, no rasterization cost, and pm_auto's own code stays reference-only rather than a copy source, since its GPLv2 license would otherwise contaminate this project's licensing. The RP1 I2C bus writes a fixed 1024-byte SSD1306 frame regardless of icons versus text, so this doesn't change the wire cost, only render-side CPU, which a direct blit keeps minimal. This ADR records the chosen approach; implementing it is deferred to a follow-up ticket once this is accepted.
