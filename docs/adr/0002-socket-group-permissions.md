# Restrict the control socket to a dedicated group

The daemon runs as root (it needs `/dev/i2c-1`, `/dev/spidev0.0`, GPIO, and the power-button input device), but the CLI must never require sudo for normal use. We considered a world-writable socket (`0666`, simplest but lets any local user send hardware commands) and per-connection peer-credential checks (`SO_PEERCRED`, more precise but more code). We chose `root:pironman` ownership at `0660`, with the `pironman` group created at install time — the invoking user adds themselves to it as a one-time manual step. This is a single-user Pi appliance, not a multi-tenant box, so group-based access control is proportionate to the actual risk.
