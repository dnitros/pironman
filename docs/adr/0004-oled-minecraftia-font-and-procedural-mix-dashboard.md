# OLED: Minecraftia font for all text, mix page as a procedural pie/bar/box dashboard

PER-19 drew OLED text with `basicfont` from `golang.org/x/image`, a zero-asset embedded bitmap font. We replaced it everywhere with the embedded `Minecraftia-Regular.ttf`, rasterized live via `golang.org/x/image/font/opentype`/`sfnt`: Minecraftia is a pixel-grid font that produces clean, unantialiased 1-bit glyphs only at its native size (verified by rendering sample glyphs and inspecting them pixel-by-pixel — 7px and 9px both anti-alias, 8px doesn't), and the font asset carries its own non-GPL license separate from `pm_auto`'s GPLv2 code, so bundling `pm_auto`'s copy of the file is not a GPL concern. No glyph cache was added: `sfnt`/`opentype` re-rasterize every glyph on every tick-driven redraw, assumed negligible at an 8px grid and roughly once a second, unverified on real hardware.

The `mix` page was rebuilt as a dashboard — CPU usage/temperature pie gauges, RAM/disk usage bars, a boxed IP header — drawn procedurally with `image`/`image/draw` and basic trig (`internal/oled/mix.go`), ported directly from `sunfounder/pm_auto`'s **original `v1` branch** (`pm_auto/services/oled_service.py`, `draw_all_info()`), which draws the same way with Pillow (`ImageDraw.pieslice`/`rectangle`/`text`) and no bitmap assets at all. An earlier pass at this ticket built a hand-drawn bitmap-icon system (network/disk/error icons blitted next to text) based on the current default branch's icon-based pages; that was the wrong reference entirely and has been deleted — no bitmap icon assets exist anywhere in the OLED subsystem. `ips`/`disk`/`performance` pages are unaffected by the dashboard rebuild and keep the existing line-based text renderer, now drawing with Minecraftia instead of `basicfont` since the font swap is global.
